# Flora Web App

Operational dashboard interface for **Flora – AI Powered Product Intelligence Platform**.

## Technology Stack
* React 18
* Vite
* Tailwind CSS
* React Router v6
* Axios
* Lucide Icons

## Setup & Running Locally

1. Copy env variables:
   ```bash
   cp .env.example .env
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build production static bundle:
   ```bash
   npm run build
   ```
