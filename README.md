# Flora Intelligence Engine

Product Data Intelligence and Evaluation Engine for Flora – AI Powered Product Intelligence Platform.

## Purpose

This module receives structured product data and produces:

- normalized product attributes
- normalized units
- product classification
- similarity signals
- duplicate candidates
- completeness metrics
- data quality information

Development in progress.
