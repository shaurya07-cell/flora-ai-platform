# Flora – AI Powered Product Intelligence Platform

## OCR & Document Processing Module

This module is responsible for document processing and Optical Character Recognition (OCR) within the Flora platform.

### Overview

The Flora OCR module features a modular design that will eventually handle:
- PDF text extraction
- scanned PDF OCR
- image preprocessing
- Tesseract OCR
- Excel processing
- text cleaning
- metadata extraction
- table extraction
- standardized document output
